# EvidenceTrail calibration reports

All calibration and replay examples use fictional CVs. Most metric reports omit full CV text and accepted quote text. The unified v2 replay artifact retains the fictional candidate result payloads, quote snippets, and rendered source pages needed for the interactive demo; the app serves the full per-candidate report on demand. The targeted scanned-CV audit retains only rejected quote snippets, cited page, and verifier reason.
